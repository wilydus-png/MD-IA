
# Midterm: Kaggle Competition

## Predicción del riesgo de desnutrición infantil en Ecuador

Proyecto desarrollado para la asignatura Fundamentos de Inteligencia Artificial.

**Competencia:** Ecuador Infant Malnutrition Competition – IISEM 2026 MCD

**Objetivo:** Desarrollar y evaluar modelos de clasificación supervisada para predecir el riesgo de desnutrición infantil utilizando Python y Scikit-learn.

**Resultado obtenido:** Accuracy público de 91,13 % en Kaggle.
